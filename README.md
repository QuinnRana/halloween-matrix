# Halloween Matrix 🎃

Interactive, mobile-ready Halloween emoji “Matrix rain” web app. Includes controls (palette, speed, size, density, glow), student info save to localStorage, CSV export, and accessibility features (prefers-reduced-motion, keyboard pause).

## Quick Start
1. Clone the repo
2. Open `index.html` in your browser — or host with GitHub Pages (workflow included).
3. Edit the site and open Pull Requests.

## Live Demo (GitHub Pages)
After pushing to `main`, the included GitHub Actions workflow will deploy to Pages. The site will appear at:
```
https://<your-user>.github.io/halloween-matrix
```
